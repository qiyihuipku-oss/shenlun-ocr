# 申论镜小白操作手册

## 你平时只需要认识四个地方

1. `app/workspace-app.tsx`：页面文字和交互。
2. `app/globals.css`：颜色、字号、间距和手机适配。
3. `lib/demo.ts`：没有真实 API 时显示的题目、OCR 和报告。
4. `.env.local`：只在本机保存 API 密钥。

## 本地打开网站

在项目文件夹空白处右键“在终端中打开”，运行：

```powershell
.\scripts\start-local.ps1
```

终端出现 `Local` 地址后，用浏览器打开。不要关闭终端窗口。

## 修改一句页面文字

在 `app/workspace-app.tsx` 搜索原文字，直接替换。保存后页面会自动刷新。

## 修改主题颜色

打开 `app/globals.css`，只改开头的变量：

```css
--paper: #f3efe6;
--ink: #14243a;
--cinnabar: #b8483a;
--teal: #4e7c78;
```

## 新增一道题

正式环境应使用管理员接口 `/api/admin/questions`。本地演示可先在 `lib/demo.ts` 的 `demoQuestions` 中复制一项，然后修改：

- `title`：题目名称。
- `type`：归纳概括、综合分析、提出对策、应用文或大作文。
- `prompt`：完整题目要求。
- `materialSummary`：材料摘要。
- `maxScore`、`wordLimit`、`rubricCount`：评分配置。

公网题目只能使用自有、获授权或可合法展示的公开材料。

## 接入真实 OCR 和批改

1. 复制 `.env.example` 为 `.env.local`。
2. 在百度智能云开通“手写作文识别（多模态）”，填写两项百度密钥。
3. 在千帆平台创建 API Key，填写 `QIANFAN_API_KEY`。
4. 重启本地服务。

密钥只能保存在服务端环境变量中，不能写进页面文件。

## 出现问题时

先运行：

```powershell
npm test
```

把最后一段错误信息交给 Codex，并说明刚刚改了什么。不要发送 `.env.local`。
